# Personal Portfolio Website

Project README | Syed Abdul Qadir Gilani

## 1. About this project

This is a personal portfolio website. It shows who I am, my work experience, skills, projects and education. It is built with plain HTML, CSS and JavaScript. It does not use any library or framework, so every file is easy to read.

## 2. What is inside this folder

| File | What it does |
| --- | --- |
| index.html | The structure of the page: headings, text, lists, links and the contact form. |
| style.css | The look of the page: colors, spacing, layout, dark mode colors, and small screens (phones). |
| script.js | The actions of the page: the footer year, the dark mode button, and the contact form. |
| README.docx / README.md | This file. It explains the project. |

## 3. Parts of the website

- Home: my name, my title and a Contact button.
- About: a short introduction and the languages I speak.
- Experience: my jobs, with dates and tools.
- Skills: programming languages, data tools, web basics, other services, and my profiles on Upwork, Fiverr, Kwork and Contra.
- Projects: four projects from my resume.
- Education: my degrees and certificates.
- Contact: my email and a form.

## 4. How each file works

### index.html (HTML)

HTML is made of tags. A tag tells the browser what a piece of content is. For example, h1 is the main heading, p is a paragraph, ul and li make a list, and a makes a link. The page is split into header, main (with sections) and footer. Every part has a comment that explains it in simple English.

### style.css (CSS)

- Colors are saved once at the top with names (CSS variables), then used everywhere.
- Dark mode has its own set of colors. It turns on when the page body has the class "dark".
- Flexbox puts the logo, menu and button in one row. Grid puts the project cards in columns.
- A media query changes sizes on small screens, so the page looks good on a phone.

### script.js (JavaScript)

- It writes the current year in the footer.
- The dark mode button adds or removes the class "dark" and remembers the choice in the browser.
- The contact form checks that all boxes are filled, then opens the visitor's email app with the message ready to send. The page has no server, so this is how the form works.

## 5. How to open the website on your computer

1. Keep index.html, style.css and script.js together in the same folder.
2. Double-click index.html. It opens in your browser.

## 6. How to change things

- Email: change it in index.html (the Contact section) and at the top of the contact part in script.js.
- Links: change the Upwork, Fiverr, Kwork and Contra links in the Skills section of index.html.
- New project: copy one project card (article tag) in index.html and change the text.
- Colors: change the values at the top of style.css, inside :root.

## 7. How to upload to GitHub

1. Open your repository on github.com.
2. Click "uploading an existing file".
3. Drag index.html, style.css, script.js and the README file into the box.
4. Write a short message, for example "Add portfolio website".
5. Click "Commit changes".

## 8. How to make a live website (GitHub Pages)

1. In your repository, click Settings, then Pages.
2. Under "Branch", choose main and the root folder, then click Save.
3. Wait one or two minutes. GitHub shows the link of your live website on the same page.
